REST Assured API Testing

QA Testing Project

Project Overview

A BDD-driven API testing framework using REST Assured with Cucumber, targeting the Petstore API. Combines the power of REST Assured's fluent assertions with Cucumber's Gherkin syntax for readable, behavior-focused API test scenarios and comprehensive endpoint validation.

Tech Stack

Java REST Assured Cucumber Petstore API BDD Maven

Key Features

  • BDD scenarios with Cucumber Gherkin syntax
  • Fluent API assertions with REST Assured
  • JSON/XML response validation and schema checks
  • Petstore API full CRUD operation coverage
  • Step definition reusability across feature files
  • Cucumber HTML reports for stakeholder visibility
